# AGENT CONTRACT

This file is a compact execution contract for coding agents.

1. READ FIRST: `ai-rules.md`, current solution version, `progress.md`.
2. PS IS IMMUTABLE: never edit `ps.md` or historical PS versions.
3. SOLUTION IS IMMUTABLE: never edit `solution.md` or historical solution versions.
4. NEW SOLUTION ONLY: changes become `solution-2.md`, `solution-3.md`, etc.
5. PROGRESS IS APPEND-ONLY: read it before changes; append intent/result/errors/fixes.
6. NO INVENTED FACTS: verify current external facts; otherwise label UNVERIFIED.
7. NO OFFICIAL-ULPIN CLAIM: prototype IDs are not official ULPIN unless an authority says so.
8. NO OWNERSHIP INFERENCE: geometry is not legal ownership.
9. PRESERVE PROVENANCE: source, version, CRS, transformation and confidence travel with derived objects.
10. VALIDATE GEOMETRY: rendering is not validation.
11. CITY AGNOSTIC: adapters/configuration vary; core engine stays common.
12. TEST EVERYTHING MATERIAL: unit + geometry + integration + regression tests.
13. LOG EVERY ERROR AND FIX: add a concise permanent entry.
14. NEVER HIDE FAILURE: leave evidence and status visible.
